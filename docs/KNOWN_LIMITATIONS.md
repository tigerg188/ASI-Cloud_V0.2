# 当前版本限制与禁止宣称事项

| 项目 | 当前状态 | 禁止宣称 |
|---|---|---|
| ZIP 导入 | 已实现 | 不得称为 GitHub 自动安装 |
| 静态扫描 | 已实现基础文件识别 | 不得称为完整代码理解或 AST 全量拓扑解析 |
| 入口识别 | 文件名候选 | 不得称为真实入口已确认 |
| 项目执行 | 未接入 API/UI，默认关闭 | 不得称为真实 Agent 已运行 |
| Python 运行时 | 仅探测宿主环境 | 不得假定 AI Studio Cloud Run 必有 Python |
| 安全隔离 | 未实现 | 不得称为安全沙盒 |
| 依赖安装 | 未实现 | 不得宣称自动安装依赖 |
| 数据保存 | 当前本地 JSON 文件 | 不得称为云端物理持久化 |
| 框架遥测 | 未实现 | 不得显示真实 Agent 节点轨迹或 Token 计量 |
| DAG | 未实现且非第一阶段目标 | 不得自动把第三方项目转换为 DAG |
| 分布式调度 | 未实现 | 不得宣称横向扩展或多 Worker |

任何未来新增功能都必须先有可复现测试，再修改状态标签。
